## Deployment

The course website deploys automatically to GitHub Pages from `.github/workflows/deploy-pages.yml`
(MkDocs Material build from the course subdirectory). One-time setting required from the
repository owner: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
