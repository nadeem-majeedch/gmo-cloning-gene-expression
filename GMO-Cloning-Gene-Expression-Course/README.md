## Course overview

This module connects three domains that are usually taught separately:

1. **Genetic engineering tools** — recombinant DNA, molecular cloning, vector systems, GMO generation.
2. **Genome editing** — CRISPR/Cas mechanisms, repair pathways, base and prime editing.
3. **Developmental & spatial gene expression** — how gene expression is regulated in space and time, and how it is measured, from in situ hybridization to spatial transcriptomics.

The through-line: **the same constructs that make GMOs are the reporters that reveal developmental gene expression.** Every cloning decision reappears as an expression-analysis decision.

## Prerequisites

- General biology and basic genetics (DNA → RNA → protein; Mendelian inheritance)
- Introductory molecular biology helpful but not assumed — Module 1 builds the foundation
- For Labs 05–08: basic Python (all scripts are provided and commented)

## Learning objectives

By completion, students can do all **42 objectives** listed in the detailed
[module roadmap](MARKDOWN/01-Introduction-to-Genetic-Engineering.md) — including:

- Define genetic engineering, recombinant DNA technology and molecular cloning
- Distinguish GMO / transgenic / cisgenic / gene-edited organisms
- Explain vectors, restriction enzymes, ligase, and every major cloning technique
- Design, screen and validate a recombinant construct end to end
- Explain CRISPR mechanisms, repair pathways and editing vs transgenesis
- Explain developmental gene expression, morphogens, GRNs and spatial/temporal patterning
- Choose among RT-qPCR, ISH, reporters, scRNA-seq and spatial transcriptomics
- Analyze gels, digest patterns, qPCR time courses, RNA-seq and spatial matrices
- Discuss ethics, biosafety and regulation with the four-layer framework

## 🌐 Website (GitHub Pages)

The entire course is also a **MkDocs Material** website: homepage with learning path, module pages with embedded diagrams and footers, laboratory and assessment sections, dataset/download pages, full-text search, light/dark mode, mobile-friendly layout.

- Website source generator: [`tools/build_site.py`](tools/build_site.py) → writes `docs/` + `mkdocs.yml`
- Site toolchain: [`requirements.txt`](requirements.txt) (`mkdocs-material`)
- CI/CD: [`../.github/workflows/deploy-pages.yml`](../.github/workflows/deploy-pages.yml) (repository root) — builds in strict mode from this subdirectory, runs link QA, and deploys via the official `actions/deploy-pages` mechanism

### Build the site locally

```bash
python -m venv .venv && .venv/Scripts/activate   # or: source .venv/bin/activate
pip install -r requirements.txt
python tools/build_site.py                       # regenerate docs/ from the course Markdown
mkdocs build --strict                            # or: mkdocs serve  (live preview at 127.0.0.1:8000)
python tools/check_site_links.py                 # link QA over the built site
python tools/probe_pages_paths.py                # serve & probe under the /gmo-cloning-gene-expression/ base path
```
