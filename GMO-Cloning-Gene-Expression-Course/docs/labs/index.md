# Laboratory section

Nine exercises that turn the theory into practice. Every lab states its type **(Wet Lab / Simulation / Demonstration / Computational)**, its expected results, data tables, viva questions and an instructor key in the [lab workbook](../guide/workbook.md). Any wet-lab component must follow your institution's approved SOP and biosafety rules.
