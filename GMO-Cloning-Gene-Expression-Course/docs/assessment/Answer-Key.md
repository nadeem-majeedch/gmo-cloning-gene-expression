## Part 2 — Short-answer model answers (condensed)

1. **rDNA technology:** joining DNA from >1 source into a propagatable molecule; Cohen–Chang–Boyer–Helling 1973 (functional recombinant plasmids in *E. coli*).
2. **Transgenic** = foreign-species DNA (Bt cotton); **cisgenic** = same-species DNA (potato with potato resistance gene).
3. **ori:** replication initiation site; without it the plasmid is lost → no colonies.
4. **Cassette:** promoter (initiation), RBS/Kozak (translation initiation), terminator/polyA (defined end/stability).
5. **MCS:** cluster of unique sites → many enzyme choices in one region; directional cloning feasible.
6. **Directional cloning:** two different enzymes on vector + insert ends → only one orientation possible.
7. **Dephosphorylation:** removes vector 5′P → blocks self-ligation; insert supplies phosphates.
8. **TA:** + fast PCR capture; − no orientation control, incompatible with blunt (high-fidelity) products without A-tailing.
9. **Type IIS:** cut outside recognition site → overhang sequence is designer-chosen → unique addresses per junction.
10. **Gibson:** 5′ exonuclease chew-back → overlap annealing → polymerase fill → ligase seal.
11. **Selection** = condition kills undesired cells (antibiotic); **screening** = per-colony test (colony PCR).
12. **Blue-white:** insert disrupts lacZα → no β-gal → white on X-gal; empty → blue.
13. **Candidate:** selection only proves "has vector"; insert presence/orientation/sequence unproven.
14. **Sanger:** actual nucleotide sequence — detects point mutations/frameshifts invisible to digests.
15. **Promoters:** constitutive = always on; inducible = signal-gated (Tet, lac); tissue-specific = spatial restriction.
16. **GFP:** autocatalytic chromophore (Ser65–Tyr66–Gly67), needs only O₂ → genetically encoded fluorescence.
17. **Luciferase:** quantitative dynamic range, plate-reader assays, dual normalization; weaker spatial detail.
18. **Morphogen/French-flag:** concentration gradient + thresholds → distinct fates at distinct distances.
19. **Colinearity:** Hox chromosomal order matches A–P expression order/timing.
20. **Neural tube:** Shh (notochord/floor plate, ventral); BMP (roof plate/ectoderm, dorsal).
21. **Determination:** fate fixed despite transplantation (classic organizer/somite experiments).
22. **Spatial/temporal:** *shh* in notochord (where); *myod1* rise at 12–18 hpf (when).
23. **Bulk RNA-seq:** averages whole tissue → a small hot region dilutes into the whole.
24. **Sense probe:** cannot pair with target → measures non-specific background/trapping.
25. **Reference validation:** housekeeping genes vary with stage/treatment → invalid normalization if unvalidated.
26. **ΔΔCt:** ΔCt = Cq_t − Cq_ref; ΔΔCt = ΔCt_cond − ΔCt_ctrl; FC = 2^(−ΔΔCt); assumes ~100% efficiency.
27. **Mosaicism:** edits after first division → different alleles in different tissues → genotyping/phenotype complications.
28. **NHEJ outcome:** indels → knockout. **HDR outcome:** donor-templated correction/knock-in.
29. **Dropout:** low transcript undetected ≠ absent biology — absence claims need care.
30. **Four layers:** scientific evidence → risk assessment → ethical considerations → policy/regulation.

## Part 3 — Long-question outlines (key points expected)

**L1.** Workflow stages with purpose/errors/validation per stage (Module 2 §2); must include screening→digest→sequencing logic.
**L2.** Comparison table mechanism/strength/limitation + one justified scenario per method (Module 4 §7); scenario justification is the discriminator.
**L3.** Each component's job + failure consequence (Module 2 §1 table); full marks require the "consequence if absent" column.
**L4.** Tag/terminator order correct; frame logic; screening + sequencing plan; enzyme choices avoid internal sites.
**L5.** Element swaps → predicted expression change; e.g., inducible promoter for toxic gene; tissue-specific promoter converts localization study.
**L6.** Three kingdoms' workflows + one landmark each (insulin; Bt/Golden Rice; supermouse/Dolly); validation level differs (colony vs Southern-era vs founder genotyping).
**L7.** Ti/T-DNA/borders/vir/binary + totipotency tie-in; disarmed systems noted.
**L8.** sgRNA→PAM→R-loop→DSB→repair choice; knockout vs knock-in from repair pathway.
**L9.** Base/prime vs nuclease: DSB-free mechanisms, bystander/off-target trade-offs, efficiency caveats.
**L10.** Transgenesis adds vs editing changes; use-both argument (e.g., edited allele + transgenic reporter); off-target/mosaicism treatment.
**L11.** DGE → fate/determination/differentiation/potency; master-regulator sufficiency caveat (myoD).
**L12.** Shh source/gradient/threshold fates (V3→MN→V2→V1); duration dependence.
**L13.** Hierarchy with cross-regulation; each layer sharpens spatial precision (Module 8 §7).
**L14.** Enhancer (distal, orientation-flexible) vs promoter (proximal, initiation) vs silencer vs operator; experimental demos: reporter assays, ATAC/ChIP, repressor systems.
**L15.** Motifs → behaviors with examples (toggle→borders; FFL→filtering; lateral inhibition→salt-and-pepper).
**L16.** Method table + decision guide (Module 11 §6); full marks require "validate broadly→spatially" logic.
**L17.** ISH workflow + probe logic + domain-vs-gradient interpretation criterion.
**L18.** Stats on ΔCt; ISH spatial validation; Western/protein check; functional follow-up (e.g., morpholino/CRISPR concordance).
**L19.** scRNA pipeline steps + claim each licenses (types; trajectories ≠ clock time).
**L20.** Reporter types + controls + validity ceiling + endogenous validation pairing.

## Part 4 — Viva answers (one-line keys)

1. Insert = DNA of interest; vector = replicating vehicle.
2. ori, selectable marker, (MCS/promoter for use case).
3. High copy amplifies toxic-gene burden → use low-copy/inducible.
4. 5′-AATT sticky overhangs (staggered cut).
5. Both leave identical 5′-GATC overhangs (compatible ends).
6. ATP.
7. Kinetics vary by ends/lengths; 3:1 is a starting heuristic.
8. White = lacZα disrupted (candidate); doesn't prove insert size/sequence.
9. Product only forms if primer sites face each other in the correct orientation.
10. Two origins/markers → build in *E. coli*, propagate/use in second host (yeast/mammal).
11. Overlap-driven annealing replaces restriction-site dependence.
12. Cuts outside recognition site → overhang bases are user-chosen.
13. Correct ligation destroys recognition sites → product can't be re-cut → accumulates.
14. Verified archive of the gene flanked by att sites for transfer to destinations.
15. No useful sites anywhere on either molecule (accept inefficiency trade-off).
16. High-fidelity polymerases produce blunt ends; TA needs 3′-A.
17. Organism carrying foreign (cross-species) DNA.
18. SCNT copied an existing genome; no new DNA was designed in.
19. T-DNA cassette plasmid + helper vir functions (disarmed Agrobacterium).
20. One modified somatic cell regenerates a whole plant.
21. Required adjacent motif for Cas9 recognition/initiation.
22. NHEJ = error-prone end joining (indels); HDR = template-directed repair.
23. HDR needs donor design, cell-cycle context; efficiency low.
24. Different edits in different cells of a founder; arises when editing post-dates the first division.
25. CRISPRi represses (dCas9-KRAB); CRISPRa activates (dCas9-activators).
26. No DSB → no dependence on HDR; deaminase acts on ssDNA directly.
27. Autocatalytic chromophore; needs only O₂.
28. Fixed-tissue spatial histology; enzyme-amplified signal (X-gal).
29. Transfection-efficiency/cell-number variation between wells.
30. Degradation-tagged reporter → reports *current* expression dynamics.
31. Missing chromatin/distal context; fusion artifacts; maturation/stability kinetics.
32. Eukaryotic translation-initiation consensus context around AUG (gccRccAUGG).
33. Expression becomes spatially restricted — localization study vs production.
34. Same genome, different transcriptional outputs across cells.
35. Concentration field instructing threshold fates (Shh; Bicoid).
36. Conserved A–P identity clusters; order matches expression order (colinearity).
37. Monotonic continuous decline vs bounded step; correlation/profile criterion.
38. Dissociation removes coordinates; spatial transcriptomics (array/imaging) restores them.
39. Non-specific background (no intended pairing possible).
40. Ct values ~normal; fold changes skewed → valid statistics on ΔCt.

## Part 5 — Case answers (key points)

**C1.** (a) resistance evolution under selection; (b) refuges keep susceptible mates available → dilute resistance alleles; (c) pest susceptibility bioassays; resistance-allele frequency monitoring.
**C2.** (a) *psy*+*crtI* complete β-carotene path in endosperm; (b) compositional equivalence, allergenicity/tox of new proteins, carotenoid bioavailability; (c) evidence→risk→ethics (autonomy, alternative interventions)→policy (approvals vary).
**C3.** Insulin: small, non-glycosylated, disulfide-processed → bacterial/yeast viable. EPO: glycosylation required for stability/half-life → CHO-class host.
**C4.** (a) epigenetic silencing; insertion position effects; allele segregation loss in breeding; (b) copy number/integration-site analysis + expression methylation assays.
**C5.** (a) models reproduce partial pathobiology; translation can fail; (b) face, construct/content, predictive validity.
**C6.** (a) NHEJ can be in-frame; functional domains may tolerate; (b) frameshift-allele screening (deeper genotyping); protein/function assay.
**C7.** (a) US product-based framing (no plant-pest DNA) → historically outside USDA; (b) EU process-based → regulated as GMO.
**C8.** (a) Hox genes specify segmental identity (ectopic gain-of-function transforms identity); (b) colinearity implies shared regulatory/chromatin mechanism rather than independent enhancers.
**C9.** (a) sufficiency of Bicoid for anterior patterning; (b) gradient forms from localized maternal mRNA → maternal supply is instructive for A–P axis.
**C10.** (a) morphogen gradient with threshold fates; (b) pulse/step experiments altering duration vs concentration independently (cell-culture assays/reporters).
**C11.** (a) dissociation discards coordinates; (b) spatial transcriptomics (spot-resolved), RNA-FISH/imaging (single-cell, subcellular localization).
**C12.** (a) hypothesis of ligand–receiver signaling axis; (b) validate by ISH/IF for both molecules + perturbation (ligand/receptor KO or CRISPRi) with downstream-target readout.

## Part 6 — Data-question keys

**D1.** Y correct (4.05+0.85 = 4.05 kb... precisely vector 3.2 + insert 0.85); X = empty vector (single 3.2 band).
**D2.** Sum = 4.9 kb ≠ 3.2 kb → rearrangement/duplication (fragment-sum rule).
**D3.** Ground truth: 14 correct / 4 empty / 2 wrong-orientation / 2 mixed / 2 PCR-failure; discrepancy example: PCR-positive blue colony (lacZα-sparing insertion) → carry to digest.
**D4.** Correct-clone rate L2 > L4 > L3 >> L1; colony count alone ranks L3 high while its clone quality is poor — screening rates, not counts.
**D5.** *myod1* 18 hpf FC ≈ 7.5× (ΔΔCt −2.9); report ANOVA on ΔCt, n=4, reference = geometric mean.
**D6.** With unstable reference, induction is artifact; stable-reference normalization reduces/abolishes it — reference validation precedes interpretation.
**D7.** 18 genes at FDR<0.05 & |log2FC|>1; top hits form a coherent 5-gene module (per provided pathway list).
**D8.** k=3 → neural (*pax6a*) / muscle (*myod1*) / blood (*hbbe1*); k=4 subcluster = low-*myod1*/low-*actc1* transition state.
**D9.** Region markers per generator script; "notochord-like" = region whose top marker is the notochord gene with contiguous spatial domain.
**D10.** r ≈ −0.6 (expression declines with distance from edge); gradient criterion = monotonic continuous decline vs bounded step; validate by ISH with sense/known-marker controls.
