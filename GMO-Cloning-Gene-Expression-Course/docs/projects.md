# Semester projects

Three capstone formats, all detailed in [Lab 09 - Capstone Project](labs/Lab-09-Capstone-Project.md). All tracks share a common spine: question -> design -> execution (simulated) -> synthesis -> defense.

## Project 1 - Design a recombinant expression construct

Design a complete conceptual plasmid: promoter, gene of interest, reporter/tag, selection marker and terminator. Deliverables: construct map, cloning plan, diagnostic-digest predictions and a validation plan. Supporting exercises: [Lab 01](labs/Lab-01-DNA-Cloning-Design.md), [Lab 02](labs/Lab-02-Restriction-Digestion.md).

## Project 2 - Developmental gene-expression analysis

Analyze the provided temporal/spatial datasets ([downloads](downloads/datasets.md)): qPCR time course, bulk RNA-seq, single-cell clusters and the spatial matrix. Deliver a reproducible notebook with figures and interpretation ([Lab 05](labs/Lab-05-Gene-Expression-Analysis.md), [Lab 08](labs/Lab-08-Computational-Gene-Expression.md)).

## Project 3 - GMO case-study investigation

Choose a real GMO (for example Bt crops, Golden Rice, recombinant insulin or a CRISPR-edited crop) and evaluate the genetic modification, molecular mechanism, intended benefit, evidence, risks, regulation and societal considerations using the four-layer framework from [Module 14](modules/14-Ethics-Biosafety-and-Regulation.md).

## Evaluation rubric (all tracks)

| Criterion | Weight |
|---|---|
| Scientific accuracy and terminology | 30% |
| Design / analysis quality | 30% |
| Interpretation and critical evaluation | 20% |
| Clarity of report and presentation | 20% |
